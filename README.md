# [ILV Map](https://ilv-map.vercel.app/)

Mapa de materias y sus correlativas de los profesorados del Instituto de Enseñanza Superior en Lenguas Vivas Juan Ramón Fernández

> Este proyecto está basado en gran parte en el trabajo de Fede del Mazo: [FIUBA Map](https://github.com/FdelMazo/FIUBA-Map) ([fede.dm/FIUBA-Map](https://fede.dm/FIUBA-Map/)), el mapa original para la Facultad de Ingeniería de la Universidad de Buenos Aires.

---

La idea de este proyecto es presentar de una manera interactiva el plan de estudios de los profesorados del Instituto de Enseñanza Superior en Lenguas Vivas Juan Ramón Fernández, para saber que materias se pueden cursar, cuantos créditos se tienen actualmente y demás.

- Tiene los profesorados de Alemán (plan 2015) y de Educación Superior en Alemán (plan 2023).

- Trackea la cantidad de créditos que se tienen en la carrera, incluyendo materias obligatorias y optativas.

- Base de datos! Se pueden marcar todas las materias apobradas y guardarlas bajo un padrón (o cualquier clave).

- Poner materias en final! Para no olvidarse los finales colgados.

---

npm install
